# Validation

Validated in the Linux cloud environment on 2026-10-28 with Godot 4.6.3 standard.

- Editor import completed; GDScript compiled.
- Official export templates were verified against the release SHA-512 manifest. Only matching single-threaded web templates were extracted.
- `godot --headless --script res://tests/runtime.gd`: **11 checks passed**: full kick, unit conversion, moving kick, opposing momentum clamp, minimum drag, floor collision/bounce, physical boost activation, pause, resume, physical goal crossing, saved best score. The test writes isolated engine user data; it does not validate browser persistence across sessions.
- `godot --headless --export-release Web`: export succeeded, producing HTML, JS, WASM and PCK.
- Chromium loaded the export over local HTTP with WebGL2 (software rendering). No console errors or page exceptions. Real mouse drag increased shots to 1 and sent the ball over the ramp; aim, pause, restart and 844×390 landscape resize were exercised. Screenshots were visually inspected; see web-preview.png, aim-preview.png, shot-preview.png and mobile-preview.png.
- Full touch gestures, physical iOS/Android hardware, Safari, Firefox, GPU performance and native exports remain untested. Touch input uses the engine's supported single-finger mouse emulation.
- Goal completion was verified with a native physics-driven crossing, not an end-to-end human browser solve. The result and score logic are covered by native runtime checks.

The browser harness requires Node, Playwright and Chromium. Serve build/web on port 8060 then run `node tests/web.cjs`. Override GAME_URL for a deployed site. Browser screenshots are written under /tmp. No preview URL is generated by local validation.

Early checks caught a PackedVector2Array UV operation and test-teleport synchronization issue; both were corrected and affected checks rerun. The restricted command sandbox also prevents Godot's editor discovery socket from binding; this is unrelated to exported gameplay and is absent when run with the environment's permitted networking execution.
