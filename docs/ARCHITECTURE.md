# V2 architecture

`levels/*.tscn` are authored scene data. Their common `@tool` level script exports identity, scoring, bounds, camera, background and gravity. Each owns transformed reusable wood instances, a Spawn Marker2D, a Goal and optional boost instances. No per-level gameplay scripts or preload of the campaign are needed. Scene filenames form the small local picker; runtime only instantiates the selected level. For thousands of levels, a lightweight world/campaign manifest can index IDs and display names without changing the scene format. Level IDs, not filenames/order, key progress. Future revisioned campaign records and world resources can be added alongside this foundation.

`Polygon2D` is the source of truth for timber vertices/UVs and generated `StaticBody2D/CollisionPolygon2D`. Native transforms carry both art and physics together; generated children have no scene owner and are reconstructed on load. Texture UVs use local units instead of stretching a complete image onto every shape. Grass is a per-object local-edge treatment. Goal dimensions produce three physical bars and matching artwork. Its open-mouth swept full-ball crossing is computed in goal-local coordinates, not world hard-coded coordinates. Use goal dimensions rather than non-uniform scaling.

`game.gd` handles runtime loading, shared UI, selection, scoring, input and camera. Running a level scene directly delegates to this shared runtime, allowing F6 to test without a campaign. The small EditorPlugin creates/duplicates native scene data and generates unique IDs. It does not own geometry editing, saving or undo: native Godot tools do. File creation is intentionally not an undoable polygon operation; ordinary edits use native undo/save.

The 120 Hz native simulation and original kick/gravity/momentum conversions remain unchanged. V2 removes the near-ball aim restriction and uses screen-relative pulls, even while the camera follows. A circle sweep (ball radius 16), rather than a centre ray, previews approximate rebounds; preview length varies with pull. Air damping/gravity are integrated approximately and boost forces are not predicted. This remains a guide, not an authoritative second physics simulation. No extra cursor tether/power bar is drawn.

The Pages workflow/version remains pinned to the tested Godot 4.6.3. A new build packages saved level scenes. No export publishing is required for F6/local iteration. Mobile platform exports, campaign importer, full editor UI in the browser and the original camera's pinch controls remain outside this increment.
